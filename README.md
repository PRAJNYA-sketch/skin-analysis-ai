# AI Skin Analysis & Face Shape Recommendation System

An AI-powered web application that analyzes facial images and provides skin concern estimates, face shape identification, and personalized styling recommendations.

## Features
- Face image upload and scanning
- Skin concern analysis
- Face shape detection
- Hairstyle and styling recommendations
- Skincare recommendations

## Technology Stack
- Python
- FastAPI
- HTML
- CSS
- JavaScript
- OpenCV
- MediaPipe
- NumPy
